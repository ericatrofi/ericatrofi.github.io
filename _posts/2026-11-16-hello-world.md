## How to write a new post

1. Create a new file in the `_posts` folder named `YEAR-MONTH-DAY-short-title.md`,
   for example `2026-12-01-my-first-real-post.md`.
2. Start it with this header (the lines between the `---`):

```
---
title: My first real post
description: One sentence shown in the list of posts.
tags: [research, art]
---
```

3. Write the post below the header in Markdown. Save, and it appears on the Blog page.
